# Oxion для iPhone

iOS-приложение, внутри которого работает твоя PWA Oxion с Cloudflare Worker.
Сервер менять не нужно: приложение открывает тот же адрес, что и PWA.

## 1. Загрузить проект на GitHub
1. Зарегистрируйся на github.com.
2. Нажми «+» → New repository → имя `oxion-ios` → Private → Create repository.
3. На странице репозитория нажми «uploading an existing file».
4. Перетащи **всё содержимое** распакованного архива, включая папку `.github`, и нажми Commit changes.
   Если папка `.github` не загрузилась (Windows её может прятать), создай файл вручную:
   Add file → Create new file → имя `.github/workflows/build-ios.yml` → вставь текст из архива.

## 2. Собрать приложение
1. Вкладка **Actions** → «Сборка iOS (Oxion)» → **Run workflow**.
2. В поле адреса вставь адрес своей PWA (например `https://fit-app.xxx.workers.dev`).
3. Run workflow. Сборка идёт ~10–15 минут.
4. Когда появится зелёная галочка, открой сборку → внизу **Artifacts** → скачай `Oxion-ipa` (zip) → распакуй → там `Oxion.ipa`.

## 3. Поставить на iPhone (бесплатно, без аккаунта разработчика)
1. Установи на Windows **iTunes** (с сайта Apple, не из Microsoft Store) и **Sideloadly** (sideloadly.io).
2. Подключи iPhone кабелем, нажми «Доверять этому компьютеру».
3. В Sideloadly перетащи `Oxion.ipa`, введи свой Apple ID → Start.
4. На iPhone: Настройки → Основные → VPN и управление устройством → твой Apple ID → Доверять.
5. На iOS 16+ включи: Настройки → Конфиденциальность и безопасность → Режим разработчика → перезагрузка.

Ограничения бесплатной установки: работает 7 дней, потом поставить заново через Sideloadly.

## Что ещё нужно до публикации в App Store
- Кнопка «Удалить аккаунт» внутри приложения (обязательно по правилам Apple).
- Вход через Apple рядом со входом через Telegram.
- Push-уведомления через Apple (APNs) — нужен платный аккаунт.
- Подпись и отправка в TestFlight — нужен платный аккаунт.
