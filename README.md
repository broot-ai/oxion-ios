# Oxion для iPhone (SwiftUI)

Родное iOS-приложение Oxion: SwiftUI, «жидкое стекло» iOS 26, раздел в «Настройках» iPhone.
Работает с тем же сервером, что и PWA (`fit-app.brootai.workers.dev`).

## Что внутри
- Вход через Telegram-бота (или кодом `/code`)
- Лента: для вас / подписки / мой город, лайки, закладки
- Тренеры: поиск, сортировка, карточка тренера, избранное
- Дневник: цель недели, подходы, калории, вес, список тренировок
- Упражнения (кнопка поиска в таббаре): по группам мышц
- Ветки постов: ответы, новый пост с фото и темой, жалобы, репосты, удаление своих
- Чаты: список с непрочитанными, переписка, фото, ответы, реакции, удаление; «Написать тренеру»
- Дневник: новая тренировка, упражнения и подходы, вес тела
- Профиль: редактирование (имя, город, цель), уведомления, поддержка, документы, выход
- «Ещё в Oxion»: маркетплейс, кабинет тренера, панель платформы — через веб-версию внутри приложения (вход переносится)
- «Настройки» iPhone → Oxion: тактильный отклик, лента при запуске, автозагрузка фото, адрес сервера

## Сборка
Каждое изменение в `main` автоматически собирается на GitHub (вкладка Actions).
Готовый файл — `Oxion-ipa` в разделе Artifacts. Установка — через Sideloadly.

## Структура
- `project.yml` — описание проекта (XcodeGen делает из него Xcode-проект)
- `Oxion/App` — запуск, таббар
- `Oxion/Core` — API, модели, настройки, Связка ключей
- `Oxion/Views` — экраны
- `Oxion/Settings.bundle` — раздел в «Настройках» iPhone
